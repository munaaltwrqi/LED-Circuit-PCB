# LED Circuit PCB Project

A simple PCB design project featuring a 5V LED circuit with a resistor, designed and routed using EasyEDA for an academic task.

## 🛠️ Components Used
* Power Supply: 5V DC (Connector `H1`)
* Resistor: 220Ω (`R1`)
* LED: Standard LED (`LED1`)
* Ground: GND

* `Gerber/` - Contains the manufacturing files (Gerber files and drill files) required for PCB fabrication.

## 💻 Software Used
* EasyEDA (Standard Edition)
* Mac OS environment for design and export.
